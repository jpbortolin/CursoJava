# Expressões Comparativas

São expressões que comparam um valor ou uma coisa com outro valor/coisa, por exemplo:

```
5 > 10 -> Falso

// "5 > 10" é a expressão
// "->" é o resultado
// "Falso" é o valor verdade
```

## Operadores Comparativos

| Operador | Significado |
| --- | --- |
| > | Maior |
| < | Menor |
| >= | Maior ou Igual |
| <= | Menor ou Igual |
| == | Igual |
| != | Diferente |
